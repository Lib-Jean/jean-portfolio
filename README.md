# Jean Jiang Portfolio

React + Vite portfolio prototype for industrial, product and interaction design work.

## Run locally

```bash
npm install
npm run dev
```

## Replace content

- Edit project records in `src/data/projects.js`.
- Edit capability cards in `src/data/skills.js`.
- Replace placeholder copy inside `src/components/`.
- Put portfolio PDFs in `public/pdf/` using the filenames defined in `projects.js`.
- The portrait placeholder is isolated inside `About.jsx` and styled in `App.css`.
